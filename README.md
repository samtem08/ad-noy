## Project Overview

AD-NOY is a business website built to highlight the client's services, portfolio, and contact options. The goal was to create a **modern, responsive, and easy-to-navigate website** that enhances the client's digital presence.

## Features

- Fully responsive layout for desktop and mobile devices
- Sections for About, Services, Portfolio/Projects, Testimonials, and Contact
- Interactive navigation and smooth scrolling
- Contact form for client inquiries
- Custom styling and design according to client requirements
